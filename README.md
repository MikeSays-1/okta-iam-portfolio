# Okta Identity & Access Management Portfolio

This portfolio documents my Okta identity and access management work within **Northwind Medical Systems**, a simulated enterprise environment used to model workforce identity, authentication, application access, and automation scenarios.

The projects focus on identity lifecycle management, federation, modern authentication, access policies, workflow automation, and troubleshooting using Okta.

## Portfolio Projects

### Part 1 — Identity Lifecycle Management, SAML SSO & Application Access
Covers user and group administration, lifecycle management, application assignments, SAML 2.0 SSO, and workforce access.

**Project:** [Part 1. Okta Identity Lifecycle Management (JML), SAML 2.0 SSO & Application Access](https://github.com/MikeSays-1/okta-identity-lifecycle-saml)

### Part 2 — OIDC, OAuth 2.0 & Authentication Policies
Covers OpenID Connect, OAuth 2.0 authorization flows, authentication policies, MFA, and access controls.

**Project:** [Part 2. Okta OIDC, OAuth 2.0 & Authentication Policies](https://github.com/MikeSays-1/okta-oidc)

### Part 3 — Okta Workflows, Monitoring & Automated Remediation
Covers Okta Workflows, identity automation, privileged-access monitoring concepts, and automated remediation.

**Project:** [Part 3. Okta Workflows: Privileged Access Monitoring & Automated Remediation](https://github.com/MikeSays-1/okta-workflow-automation)

### Part 4 — Okta OIN Integration & Group-Based Access Management
Covers application integration, group-based assignment, access administration, and application-access management.

**Project:** [Part 4. Okta OIN App Integration & Group-Based Access Managment](https://github.com/MikeSays-1/okta-oin-access)
